### ZAPRET-Linux-Windows

🛡️ **ZAPRET** - это кроссплатформенный набор инструментов для обхода блокировок интернет-сервисов, таких как YouTube, Discord и других, на операционных системах Linux и Windows.

## 🚀 Возможности

*   **Linux (мощный обход):**
     На данный момент поддерживаются дистрибутивы:
- Debian
- Fedora, Ubuntu
- Arch Linux, Artix Linux (и их производные)
- Alt Linux
- Void Linux
- Aipline Linux

*   **Windows (мощный обход):**
- ну винда одна, так что нету смысла что-то говорить

---

## ⚙️ Установка

### Linux
просто сделайте одну команду и у вас встанет всё на свои места!:

```
sh -c "$(curl -fsSL https://raw.githubusercontent.com/web-pentest/ZAPRET-Linux-Windows/main/linux/installer.sh)"
```

### Windows
Откройте папку с Виндой которую вы скачали и откройте general.bat, всё.
