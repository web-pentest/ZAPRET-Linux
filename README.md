### ZAPRET-Linux

🛡️ **ZAPRET** - это кроссплатформенный набор инструментов для обхода блокировок интернет-сервисов, таких как YouTube, Discord и других, на операционных системах Linux.

---

## 🚀 Возможности

*   **Linux (мощный обход):**
     На данный момент поддерживаются дистрибутивы:
- Debian
- Fedora, Ubuntu
- Arch Linux, Artix Linux (и их производные)
- Alt Linux
- Void Linux
- Aipline Linux

---

## ⚙️ Установка

### Linux
просто сделайте одну команду и у вас встанет всё на свои места!:

```
sh -c "$(curl -fsSL https://raw.githubusercontent.com/Snowy-Fluffy/zapret.installer/refs/heads/main/installer.sh)" 
```
